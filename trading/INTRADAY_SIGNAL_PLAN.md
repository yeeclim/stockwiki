# 장중 변동성 캐치 — 현황과 계획

작성일: 2026-09-30. 코스피가 아침 "강세 우세" 신호와 반대로 −0.48% 하락 마감한 것을
계기로 정리.

## 1. 지금 뭐가 있고, 뭐가 틀렸는가

### 이미 있는 것
- **적중률 추적** (`forecast_log.py`): `screen.py`가 06:30 장전 판정을 `market_forecast_log`
  테이블에 자동 기록하고, 장 마감 후 실제 시가/종가를 붙여 채점한다.
  - `gap_pct` (시가/전일종가): 신호가 실제로 예측할 수 있는 구간
  - `close_pct` (종가/전일종가): 하루 전체 — 장중 재료는 모델 입력에 없어 여기서
    맞으면 상당 부분 운
  - 기준선(그냥 "항상 강세"로 찍었을 때 적중률) 대비 초과분까지 계산
  - 가동 시작: 2026-09-16 마이그레이션(`20260916000002_market_forecast_log.sql`).
    2026-09-30 기준 약 15일치 — 코드 자체가 "30일 미만은 우연" 경고를 낸다.
- **상관 그룹 집계** (`market_signals.py`): 지표 하나당 1표가 아니라, 상관된 지표를
  그룹으로 묶어 그룹당 1표. 예: 미국 증시/VIX/미국채10년 = "미국 위험선호" 그룹 1표.
  SK하이닉스 ADR(SKHY)은 야간선물·EWY·정규선물·미결제약정과 "국내 야간·선물" 한
  그룹으로 묶여 있다. KORU는 EWY와 같은 지수의 3배라 신호에서 아예 제외(표시만).
  → 지표를 늘려도 상관돼 있으면 표가 안 늘어나게 설계돼 있다.

### 왜 오늘 틀렸는가
- 코스피 9/30: 시가 6,943pt(갭 상승) → 종가 6,838.04(−0.48%). 즉 **개장 시점까지는
  신호 방향이 맞았고**, 이후 장중 매물 소화로 반전했다.
- `_compute_signals`의 모든 입력(간밤 미국장, 야간선물/EWY, SKHY, 원/달러, 유가,
  금리, 전일 수급)은 **06:30 시점에 확정된 값**이다. 장중에 나오는 새 재료(차익실현,
  섹터 로테이션 등)는 애초에 모델에 들어갈 방법이 없다.
- 결론: "장중 변동성을 예측 못 한 것"이 아니라, **장중 변동성은 이 시스템의 입력
  범위 밖**이다. 더 많은 사전 지표를 넣는다고 해결되지 않는다.

## 2. 장중 변동성을 "캐치"하려면

예측이 아니라 **장중에 다시 관측하는 체크포인트**가 맞는 접근이다.

| 지표 | 왜 | 난이도 |
|---|---|---|
| 장중 재조회(11시/13시경) | `kis_api.get_investor_trend()`는 `FID_INPUT_DATE_1=오늘`로 조회 — 장중에 불러도 그 시점까지 누적된 실제 수급이 나온다. 새 API 불필요, 다른 시각에 한 번 더 호출하면 됨 | 낮음 |
| 선물-현물 베이시스 | 코스피200 선물가 − 현물지수. 베이시스 급변은 단기 방향전환의 고전적 선행신호 | 낮음~중간 |
| VKOSPI(한국 자체 변동성지수) | 지금은 미국 VIX를 국내 불안심리 대용으로 씀. 직접적 대체재 | **미검증** — 무료 실시간 소스 확인 안 됨 |
| 프로그램매매 순매수 | 장중 수급 방향의 실시간 프록시로 잘 씀 | **미검증** — KIS/네이버 무료 엔드포인트 여부 확인 안 됨 |
| 업종 등락 폭(breadth) | "지수 하락 + 철강주 급등"처럼 소수 종목 쏠림인지 전반적 추세인지 구분 | 중간 |

## 3. 다음 단계 (합의된 순서)

1. **장중 체크포인트 하나 추가** (11시 또는 13시). 같은 신호 로직을 다시 돌려
   06:30 판정과 비교. `market_forecast_log`에 체크포인트 구분 컬럼을 추가해
   "장전 판정 vs 장중 재판정 vs 실제 종가" 3단 비교를 데이터로 남긴다.
2. 최소 30일 쌓이면 그 체크포인트가 실제로 종가 적중률을 높이는지 `forecast_log.py
   report`로 검증.
3. 검증되면 베이시스 등 추가 지표를 같은 방식(체크포인트 + 채점)으로 하나씩 검증
   후 도입. 검증 없이 지표만 늘리지 않는다 — 그게 지금 설계 전체의 원칙이다.
